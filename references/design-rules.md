# 设计规则与踩过的坑

需要自绘插画、写 `custom` 版式,或者体检报了看不懂的问题时读这份。常规出图只需要 spec-format.md。

## 风格从哪来

参照 claude.com / anthropic.com 的视觉语言,但**只借气质,不借身份**:

- 暖米白底 `#FAF9F5`,近黑墨色 `#141413`,陶土橙 `#D97757` 是唯一主强调色。
- 标题用常规字重的衬线体(New York + 宋体),不加粗。官网标题的高级感来自「大而细」,加粗会变成海报腔。
- 插画是粗黑手绘线 + 平涂色块(米白 / 陶土橙 / 马尼拉黄 `#EBDBBC`),线条带一点抖动。
- 产品感元素用 Claude Code:浅色圆角输入框 `> /命令`、深色终端、✻ 星号。
- 不画 Claude / Anthropic 的 logo 和字标,也不写成官方口吻。图是用户个人发的,看起来像官方物料会误导读者,也有冒用品牌的风险。

## 字号与容量(1600 宽画布)

缩略图里只看得清标题,正文是给点开看的。所以标题要大、要短;正文宁可少写。

| 元素 | 字号 | 容量参考 |
|---|---|---|
| split 大标题 | 104 | 左栏 768 宽 ≈ 7 个汉字/行,2 行 |
| flow / compare 标题 | 78 | ≈ 17 个汉字,1 行 |
| split 副标题(衬线) | 34 | 左栏 600 宽 ≈ 17 个汉字/行 |
| split 正文段落 | 29 | 左栏 768 宽 ≈ 24 个汉字/行 |
| 站点标签 | 30 | 300 宽 ≈ 8 个汉字 |
| 站点说明 | 23 | 300 宽 ≈ 12 个汉字/行,2 行 |
| 终端 | 21 等宽 | ≈ 27 个汉字/行 |

估算规则:1 个汉字 = 1 个字号宽;英文、数字约 0.55 个字号宽;等宽字体 0.6。

## 手绘插画配方(自绘 `svg` 时照着做)

```svg
<svg viewBox="0 0 224 318">
  <g filter="url(#rough)" stroke="#141413" stroke-width="4" stroke-linejoin="round" stroke-linecap="round">
    <ellipse cx="112" cy="306" rx="88" ry="8" fill="#141413" fill-opacity=".1" stroke="none"/>  <!-- 落地阴影 -->
    <path d="…主体…" fill="#FAF9F5"/>              <!-- 主体米白或白 -->
    <path d="…点缀…" fill="#D97757"/>              <!-- 一处陶土橙 -->
    <path data-star="40,90,16" fill="#FAF9F5" stroke-width="3"/>   <!-- 四角星:页面脚本按 x,y,半径 生成 -->
    <text font-family="Hannotate SC" font-size="34" font-weight="700" fill="#141413" stroke="none">手写标注</text>
  </g>
</svg>
```

- 滤镜 `#rough`(抖动 3.5)适合小插画,`#rough-lg`(4.5)适合 split 右侧大插画。页面里已经定义好,直接引用。
- 线宽:小插画 3~4.5,大插画 5~5.5。线太细就不像官网插画了。
- 每幅插画只用一处陶土橙。其余用米白、马尼拉黄或留白。
- 手写标注用 Hannotate SC,再配一条手绘弯箭头指向对象,就是官网插画那种「批注感」。
- 隐喻优先用字面双关(瓶颈 → 瓶子,交付 → 插旗,拆票 → 文档变成一叠票),读者一眼就懂。

## 踩过的坑

- **别用 `<use>` + `scale()` 复用星星**:描边会跟着放大,星星变成黑色墨团(`vector-effect` 在 `<use>` 上不管用)。一律用 `data-star`。
- **页面 class 别和组件 class 撞名**:版式 class 已经带 `t-` 前缀。早期 `flow` 版式和 `.flow` 容器撞名,整张图被推偏了 88×322px。写 custom 版式时同样注意。
- **标题标点**:New York 字体会把全角「：」「，」渲染成窄的西文形状,宋体又会留一个全角空。脚本对标题做了挤压(`.pc` / `.pm`),正文不挤。
- **中文别让浏览器自动断行**:容易断出「……新会 / 话，」这种孤字。重要句子用 `\n` 自己断,体检也会报孤字。
- **拼图网格要写死行高**:否则图片按原始尺寸撑开,预览会错位(脚本已修)。
- 体检的「自动缩字」只是提示(`·` 开头)。缩到 14px 以下会被截断并报 ⚠,这时去缩短命令参数,比如 `…/23`。
